# Bring one useful source

You can contribute a repository, release, research finding, correction, community venue or camera test report. [Open an issue](https://github.com/xulfr/om-firmware-atlas/issues/new/choose), or prepare a PR using [CONTRIBUTING.md](../CONTRIBUTING.md).

## Ask an agent

> Read AGENTS.md and follow agents/start.md in xulfr/om-firmware-atlas. Add this source: SOURCE_URL. Synthesise the useful delta, update the relevant records and human pages, validate, and raise a PR for human review.

The entry route is [AGENTS.md](../AGENTS.md). Agents inspect relevant releases, branches and reports as well as READMEs. They reuse existing topics and records, preserve missing details and generate the human views in the same change.

## Report a camera result

Name the exact camera/generation, stock firmware, mod build and package digest if available. Describe what you did and what happened, including failures and recovery attempts. State what you did not check. Unknown details can remain unknown; do not fill them from what a release was expected to contain.

Humans review and merge. The Atlas is a documentation home; implementation fixes belong with their upstream authors. [See the research starting guide](research.md) for choosing a contribution destination.
