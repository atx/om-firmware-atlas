## A map, with visible gaps

The Atlas connects independent work. Firmware builds, emulators and look editors stay in their own projects. This first catalogue covers a selected set of reviewed sources; missing entries mean there is more to catalogue.

**A published release, an emulator result and a camera report answer different questions.** Results belong to a specific model, firmware, project and package. An overall positive report may still lack detailed checks. [Read the evidence guide](evidence.md) before interpreting a status table.
