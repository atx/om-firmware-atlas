# Find people; preserve useful findings

Start with the [community directory](../views/community/index.md). r/M43 is a broad photography subreddit; the Caduceus Discord invite is published by the OM-3 project and confirmed for this directory by the Atlas maintainer. Read each venue's rules and project guidance before posting.

For a reproducible bug, the implementation project's issue tracker is usually the durable destination. For discussion, questions or finding collaborators, a community venue can help. A link here does not imply official affiliation, guaranteed support or agreement with every claim posted there.

## From a discussion to documentation

Give a contributor or agent a specific post/message link and the relevant camera/project context. Preserve author/date, distinguish a firsthand result from a repeated account, and extract the useful finding with its limitations. A server invitation alone is not a technical source.

Public links and permission to republish content are separate matters. Private messages/channels need an approved publication scope. A short attributed summary is usually more useful than a transcript. Do not publish serial numbers or unrelated personal details.

Venues have their own records, source references and last-check dates. Add or correct one through [the contribution workflow](contribute.md). Invite links can expire; “linked, not joined” describes a source check rather than a claim to have inspected the server.
