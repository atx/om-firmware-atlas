# 0001 — A documentation atlas with generated views

Status: accepted for initial implementation, 17 November 2026.

The community has overlapping research across independently maintained projects. The Atlas owns cross-project discovery, scoped assertions and provenance; implementations and detailed notebooks remain upstream.

Use YAML records, JSON Schemas and Markdown explanations. Generate cheap agent routes and human views from the same records. Keep observations independent of capability assertions. Do not use a single supported/safe maturity badge. Distinguish original OM-5 and Mark II, exact artifacts and incomplete reports.

Alternatives considered: a link-only catalogue cannot answer status questions; copying every notebook creates drift and context cost; a service/database is unnecessary for this initial corpus. The cost of structured records is some authoring/validation work. Small grouped files and templates limit that cost.

The user created the repository with Apache-2.0. Preserve that choice for original Atlas contributions. The earlier OpenM43 archive informed discovery, but its prose is not imported; linked work retains its own terms.

Agents normally raise PRs and humans review merges. The user explicitly authorised direct-main pushes for this bootstrap and will protect main afterwards.
