# Editor

Start from canonical records and the relevant explanation. Define terms, explain practical consequences and link the evidence. Distinguish “no record yet” from a documented negative result.

Write for a camera owner or researcher who has not read the agent conversation. Avoid unsupported compatibility language and bare “safe” badges. Put changing status in generated views rather than maintaining a second manual table.

Inspect the rendered pages and navigation, including narrow screens when layout changes. Keep the human and agent routes useful in the same change. Use the Librarian role if source assertions need reconciliation.
